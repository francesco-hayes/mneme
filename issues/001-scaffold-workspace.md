# 001: Scaffold workspace and app shell

Status: done · PRD: [00](../prds/00-foundation.md) · Lane: base · Depends on: — · Owns: whole repo (except `prds/`, `issues/`, `mneme-scope.md`)

## Goal

A repository every other issue can build in: Tauri 2 app, Cargo workspace with one crate per area, shared types, and a typed frontend API with a mock.

## Scope

1. **Cargo workspace** at the repo root with members `crates/mneme-core`, `crates/mneme-audio`, `crates/mneme-transcribe`, `crates/mneme-store`, `crates/mneme-pipeline`, `src-tauri`. Shared `[workspace.package]` (edition, MIT license, version `0.1.0`) and `[workspace.dependencies]` for crates used in more than one place.
2. **`mneme-core`** with the shared types exactly as in PRD 00: `SAMPLE_RATE`, `Speaker` (with `Display` giving `Me` / `Them` and `FromStr`), `AudioFrame`, `Segment`, `format_timestamp`, `parse_timestamp`. Serde derives. Unit tests for the timestamp functions, including hours above 99 and malformed input.
3. **Empty area crates**: `mneme-audio`, `mneme-transcribe`, `mneme-store`, `mneme-pipeline` each with a `lib.rs` holding a one-line crate doc and a dependency on `mneme-core`. No feature code.
4. **Tauri 2 app** in `src-tauri`: bundle identifier `app.mneme.desktop`, product name `Mneme`, minimum macOS 14.4, one main window (title `Mneme`, sensible default and minimum size), a strict content security policy with no remote sources. No commands yet.
5. **Frontend**: Vite + React + TypeScript with pnpm. Vitest and React Testing Library set up with one passing test. ESLint and Prettier with default rules.
6. **API module** at `src/lib/api/`:
   - `types.ts`: the contract from PRD 05, verbatim.
   - `mock.ts`: an in-memory implementation with a few seeded meetings (one interrupted), seeded transcript lines, a small model catalog with none or one installed (switchable), simulated download progress, and a working recording state with a ticking timer.
   - `tauri.ts`: a stub where every method throws "not implemented" (issue 021 fills it in).
   - `index.ts`: exports `api`, choosing Tauri when running inside Tauri and the mock otherwise.
7. **Placeholder UI**: one page that lists the mock meetings, to prove the wiring.
8. **Repo files**: `LICENSE` (MIT, Francesco Hayes, 2026), `README.md` (what Mneme is, how to build and run, pointer to PRDs and issues), `.gitignore` (target, node_modules, dist, model files, `.DS_Store`, WAV files).

### What was built

Serde derives on the three types. Only dependency: `serde`. 16 unit tests.
  - `format_timestamp` truncates milliseconds and grows the hours past two digits (`100:00:00`).
  - `parse_timestamp` accepts exactly what `format_timestamp` writes: two or more hour digits, two-digit minutes and seconds below 60. Anything else is an error, including whitespace, signs, fractions and overflow.
- **Area crates** `mneme-audio`, `mneme-transcribe`, `mneme-store`, `mneme-pipeline`: one crate doc line each and a dependency on `mneme-core`. None depends on another area crate.
- **Tauri app** in `src-tauri`, crate `mneme` (library `mneme_lib`, binary `mneme`): identifier `app.mneme.desktop`, product name `Mneme`, minimum macOS 14.4, one window `main` titled `Mneme` (960x680, minimum 640x480, centered), capability `core:default` only, no plugins, no commands. Bundle target is `app` only. Placeholder icon generated by `src-tauri/icons/make_icon.py`.
  - CSP: `default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; font-src 'self' data:; connect-src ipc: http://ipc.localhost; object-src 'none'; frame-src 'none'; base-uri 'self'; form-action 'none'`. The two `ipc` sources are Tauri's own channel to the Rust side.
  - Three tests in the crate read `tauri.conf.json` and fail if the identifier, minimum macOS or window title change, if the CSP gains any source outside a local-only list, or if a plugin or updater setting appears.
- **Frontend**: Vite 8 + React 19 + TypeScript 6 with pnpm 11. Vitest 5 with jsdom and React Testing Library; ESLint 10 (flat config: JS, typescript-eslint, react-hooks and react-refresh recommended sets) and Prettier with default rules. `pnpm lint` runs ESLint, then Prettier in check mode.

### Deviations and choices

- **`pnpm tauri dev` runs on the mock for now.** The issue says `index.ts` picks Tauri inside Tauri; PRD 00 says `pnpm tauri dev` shows the placeholder on the mock. Both hold: `index.ts` follows the issue's rule, with a build-time override `VITE_MNEME_API=mock|tauri`, and `beforeDevCommand` in `tauri.conf.json` is `VITE_MNEME_API=mock pnpm dev`. A built app uses the Tauri stub, so the placeholder there shows "api.listMeetings is not implemented yet (issue 021)".
- **`types.ts` is excluded from Prettier** so it stays character for character as in the PRD (single quotes, one-line interfaces). The only addition is `export` on each declaration.
- **`style-src 'self'` with no `'unsafe-inline'`.** Nothing in the scaffold needs inline styles, so the CSP starts at the strictest setting. See the follow-up for 017.
- **`[workspace.dependencies]` holds only `mneme-core`, `serde` and `serde_json`.** Cargo 1.100 warns about every workspace dependency nothing uses, so entries for later crates were left out.
- **Extra files**: `mockSeed.ts` beside `mock.ts`, `.cargo/config.toml`, the config tests in `src-tauri/src/lib.rs`, `@tauri-apps/api` as a dependency (for `isTauri()`, and issue 021 needs it but does not own `package.json`).
- **Mock model sizes** are the real file sizes from the model source's file listing on 2026-11-12. Model ids, names and notes are placeholders.

### The mock API, for issues 015 to 020

README.md has the full guide under "The mock API". In short:

- `import { mockApi, mockScenarios, createMockApi } from "src/lib/api/mock"`. `mockApi` is the instance `api` points to in the browser and in tests; `src/test/setup.ts` resets it after every test.
- Controls on `mockApi.mock`: `reset(options)`, `setInstalledModels(ids)`, `setPermission(kind, value)`, `putMeeting(seed)`, `failNext(method, message)`, `failNextDownload(message)`, `revealedInFinder`.
- Scenarios: `default`, `first-run`, `empty`, `long-transcript` (2,000 lines). In the browser: `/?mock=first-run`, and `&mockLatency=300`. In the dev console: `__mnemeMock`.
- `generateTranscript(n)` in `mockSeed.ts` makes a deterministic transcript of any length.
- Seed: `mtg-standup` (complete, 12 lines), `mtg-design-review` (interrupted, 8 lines), `mtg-untitled` (default title, no notes, 0 lines), `mtg-planning` (214 lines). Model `base` installed out of five; both permissions granted; language `auto`; no shortcut.
- With fake timers, `await vi.advanceTimersByTimeAsync(3000)` moves a recording three seconds. A default download is 20 steps of 150 ms, then 600 ms of `verifying`. `stopping` lasts 600 ms; `stopDelayMs: 0` removes the wait.

Behaviour the contract does not spell out, which the mock had to pick. Issue 021 should match these or change the mock:

1. `downloadModel` resolves when the download starts; progress and the outcome (`done`, `cancelled`, `error`) arrive only through `onDownloadProgress`. It rejects for an unknown, installed or already downloading model.
2. `stopMeeting` resolves when the meeting is complete; the state is `stopping` until then.
3. Installing a model does not set `defaultModelId`. Deleting the default model sets it to null. `startMeeting` uses the default model, or any installed one if no default is set.
4. `startMeeting` rejects when a recording is running, when no model is installed, or when the microphone is denied. A denied system audio permission still records.
5. `renameMeeting` rejects an empty title and a folder-name clash. While recording, the title changes at once and `folderPath` at stop.
6. `deleteModel` rejects for the model a running recording uses.
7. `startedAt` is ISO 8601 in UTC (`...Z`). `Settings.language` is `auto` or a language code.
8. The Tauri stub's promise methods reject; `onRecordingState` and `onDownloadProgress` throw.

### Follow-ups

- **Each area lane (002, 005, 010, 009):** `cargo` prints `unused dependency mneme-core` for your crate until the crate uses a `mneme-core` type. It is a manifest warning, not a compile warning, and does not fail clippy.
- **Each area lane:** the root `Cargo.toml` is outside your folder. Declare your dependencies in your own crate's `Cargo.toml`. If a crate should be shared, or a `[profile]` setting is needed (for example optimising dependencies in dev builds so resampling or Whisper is not slow under `cargo test`), list it as a follow-up for the orchestrator.
- **005:** the root `.gitignore` ignores `*.wav` and `*.bin`. To commit the speech fixture, add a `.gitignore` inside the crate that re-includes it (for example `!tests/data/*.wav`).

If styles are missing there and not in the browser, the CSP in `src-tauri/tauri.conf.json` is the place to look (app lane).
